About This Project

VR environment in Unity for controlling virtual drones using Meta Quest controllers, LLM agents, and speech commands.

  • Built with Unity and C#.
  • Uses VR Meta Quest controllers to control virtual drones.
  • Uses voice commands with integrated LLM agents to control virtual drones.
  • Uses Eye-Gazing to let virtual drones fly to the destination where the player look.
  • Can control the drones with keyboard and mouse on PC.
