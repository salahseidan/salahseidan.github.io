About This Project

Bowling VR is a Unity VR practice project focused on creating an interactive bowling experience. The project help beginners practice VR scene setup, object interaction, physics-based gameplay, and C# logic inside Unity.

  • Built with Unity and C#.
  • Uses VR interaction basics for grabbing and throwing.
  • Includes a bowling environment, pins, ball, and gameplay objects.
  • Created as a learning project for VR development workflows.
